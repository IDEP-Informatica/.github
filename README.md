# .github

Repositorio especial de la organización **IDEP Informática**. El archivo [`profile/README.md`](profile/README.md) es lo que se muestra en la página pública de la organización en GitHub.

- `profile/README.md`: texto del perfil.
- `profile/assets/banner.svg`: banner animado. Se genera con `profile/assets/src/build_banner.py` (logo y tipografías Roboto embebidos).
- `profile/assets/idep-informatica-avatar.png`: emblema circular para usar como avatar de la organización.
- `profile/assets/logos/`: logos de ATE, IDEP y CTA, en color (tema claro) y blanco (tema oscuro).

Identidad visual tomada de [idepba.com.ar](https://www.idepba.com.ar/): verdes institucionales (`#013220`, `#004225`, `#00693E`, `#289548`) y familia Roboto.
